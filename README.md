## 1. Limitações do Perceptron

Voltado para o estudo do algoritmo Perceptron e suas limitações em problemas de classificação linear. Foram realizados testes utilizando diferentes distribuições de dados e cenários com outliers, analisando o impacto desses elementos na capacidade de separação do modelo, desempenho e generalização.

    Principais tópicos abordados:
    - Caso perfeito para o perceptron
    - Casos não linearmente separáveis
    - Instabilidade do modelo
    - Sensibilidade a Outliers

## 2. Detecção de Fraudes Bancárias com One-Class Classification

Sistema de detecção de fraudes bancárias treinado utilizando apenas instâncias da classe “não-fraude”. O projeto aplica técnicas de aprendizado de máquina para identificar comportamentos anômalos, simulando cenários reais onde exemplos de fraude são raros ou indisponíveis durante o treinamento.

    Principais tópicos abordados:
    - Detecção de anomalias
    - One-Class Classification
    - Pré-processamento de dados
    - Avaliação do modelo
    - Identificação de transações suspeitas

Os projetos têm como objetivo explorar conceitos fundamentais de Machine Learning, analisando tanto limitações de modelos lineares quanto aplicações práticas de detecção de anomalias em dados financeiros.
